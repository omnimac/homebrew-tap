# Homebrew tap for Omni

[Omni](https://www.getomni.space) is a Mac app that turns email into clicks, beside Apple Mail. It needs a Mac with Apple silicon on macOS 26 Tahoe or later.

```bash
brew install --cask omnimac/tap/omni
```

`brew upgrade` picks up new versions. The cask is written by Omni's release process, so please don't edit it by hand.
